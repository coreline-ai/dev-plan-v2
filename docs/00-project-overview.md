# 프로젝트 개요

`/Volumes/Eprojects/project_202607/dev-plan-v2`는 `codex-dev-plan-orchestrator`의
원본 저장소다. 목적은 개발계획을 간단히 만들고, 명시적인 요청에서만 구현·재개·QA를
안내하는 것이다.

## 제공 범위

- Markdown 계획 생성
- 계획의 기본 형식 검사
- PLAN / EXECUTE / RESUME / QA / STATUS 운영 지침
- 최소 런타임 파일 패키징

이 스킬은 상태 엔진, evidence 저장소, 자동 rollback, worktree 관리자, 별도 Codex
프로세스를 제공하지 않는다.
